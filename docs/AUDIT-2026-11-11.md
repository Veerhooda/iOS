# Audit & Round 1 fixes (2026-11-11)

Read of the real code/logs vs. the previous handover. What was actually wrong,
and what round 1 changes.

## Round 1 changes (kernel only, no rootfs reflash)

- `op2_autoinput=` new boot-arg. `0` none, **`1` (default) wake-only**: pulse Home until the Lock Screen is lit, then stop forever. `2` = old full test script.
- Framebuffer double buffering (`op2fb_double=1` default): back buffer in carveout slot 1 (0x03c00000); copy -> flip VIG0 SRC0 -> flush/kick.
- SwapEnd triggers an immediate present (no waiting for the next 60 Hz tick).
- Kicks are deferred to keep >= 15.6 ms spacing, never dropped.
- SwapWait implemented (`op2fb_swapwait=1` default): blocks the caller until its swap token has been presented (50 ms cap). First 6 calls log their args to confirm the token semantics.
- Per-frame logging removed; `OP2 FB PERF:` line every 600 presents (avg/max present time, deferrals, swapwait waits/timeouts).
- `OP2 CPU: cpuN effective clock ~X MHz` at boot (PMU cycle counter vs 19.2 MHz timer; `op2_cpumhz=0` disables).
- `tools/build-daily.sh`, `tools/boot-daily.sh`, `tools/pull-log.sh`.

## Next (depends on round 1 log)

- If clock << 1555 MHz: A53 PLL + APC0 voltage bring-up (careful: needs PMIC/CPR, see reference/kernel-oneplus-msm8994/drivers/clk/qcom/clock-cpu-8994.c).
- MDP5 VIG0 hardware scaler: scan 1242x2208 with bilinear filtering instead of CPU nearest-neighbour (sharper text, no 6 ms copy).
- Rootfs: disable assistivetouchd, set Reduce Transparency (software blur is the most expensive CA effect), auto-lock never.
- Crash inventory from the exit ring under real use.
