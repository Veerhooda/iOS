# Docs index

Start here, in this order. Everything is written so you can follow it without
already knowing the project; dated milestone files are history (kept as-is),
everything else describes the current tree.

| Read | Why |

| `CLAUDE.md` (repo root) | Safety rules + current state in one page |

| `docs/GPU-PLAN.md` | GPU bring-up (Metal on Adreno 430): history and next steps |
| `docs/HOW-IT-BOOTS.md` | How the phone goes from TWRP to SpringBoard |
| `docs/RESTORE.md` | How to recover the phone to a known state |

| `docs/PEER-FINDINGS.md` | What sibling iOS-on-Android projects learned |
| `docs/FABLE-REVIEW.md` | The GPU deep-review (long; only if you work on the GPU) |
| `docs/OP2_KERNEL_CHANGES.md` | What we changed in XNU and why |
| `docs/milestone-*.md` | Dated verification records, oldest first (history, not guides) |
